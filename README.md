# Projet-red_ADVENTURE BRIH

# présentation du jeu

Aimez vous l'aventure et la résolution d'énigmes ? Si oui , vous êtes au bon endroit! Nous vous présentons le jeu du nom de "Aventure BRHI" 
Dans ce jeu vous serez amené à rechercher des habittants d'un village qui ont mytstérieusement disparu.
Pandant ce périple vous devrez vous organisez dans votre "Inventaire" , à faire les bons choix et surtout  reflechir, car il vous arrivera de tomber  sur des bandits intélèctuels , trouver des objets qui peut-être vous servirons ou pas . Je n'en dirai pas plus!

# Installation du jeu

Il s'agit d'un jeu qui se déroule dans le terminal. Pour jouer au jeu:
-Créer un dossier pour mettre le dossier src
-Installer le langage Go sur l'ordinateur
-Installer un éditeur de code (VS STUDIO)
-Ouvrer le dossier créer dans vs studio 
-Dans le terminal du dossier (ctrl + j) taper la commande go run . pour lancer le programme


# Commandes

Le jeu fonctionne avec des choix affichés dans le terminal. Le joueur sélectionne les differentes options en entrant le numéro correspondant.


# Fonctionnalités

-Création de personnage(choix de classe, choix d'équipement)
-Exploration (où l'aventure commence)
-inventaire
-Fabrication d'outils à partir des objets que vous aurez ramasser
-Marchand 
-Entraînement
-Combat
-Gestion des points de vie, de l'expérience et de l'argent
